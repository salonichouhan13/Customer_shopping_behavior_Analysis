# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project focused on analyzing customer shopping behavior and transforming raw retail data into meaningful business insights using **Python, SQL, and Power BI**.

This project covers the complete analytics workflow — from data cleaning and exploratory analysis to SQL-based business analysis, dashboard creation, and business recommendations.

---

## 📌 Project Overview

Understanding customer shopping behavior is essential for businesses to improve customer retention, increase sales, optimize marketing strategies, and make data-driven decisions.

In this project, customer shopping data is analyzed to identify:

- Customer purchasing patterns
- Popular product categories
- Customer segmentation
- Spending behavior
- Subscription patterns
- Discount usage
- Product ratings
- Purchase frequency
- Sales and customer trends

The analysis combines **Python for data preparation and exploration, SQL for business analysis, and Power BI for interactive visualization**.

---

## 🎯 Objectives

The main objectives of this project are:

- Clean and preprocess raw customer shopping data.
- Perform Exploratory Data Analysis (EDA).
- Analyze customer purchasing behavior.
- Answer business questions using SQL.
- Identify important customer and product segments.
- Build an interactive Power BI dashboard.
- Generate actionable business insights.
- Provide recommendations that can support business decision-making.
